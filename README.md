## 🛠️ Usage

1. **Launch** roblox-safexec by double-clicking the `.exe` file.
2. The main window will appear with a simple text editor and a **"Run"** button.
3. Paste or write your Roblox Lua script in the editor.
4. Click **"Run"** – the script executes inside a secure sandbox.
5. View output or errors in the bottom console panel.
6. Use **"Stop"** to halt execution at any time.

**Tips:**
- Always test scripts from unknown sources here first.
- The sandbox blocks file system access, network calls, and system commands by default.
- You can enable advanced permissions via the **Settings** tab (for trusted scripts only).

## ❗ Troubleshooting

**Issue: "Windows protected your PC" warning when running the .exe**  
This happens because the file is unsigned. Click **"More info"** → **"Run anyway"** to proceed. It’s safe—the source code is open and audited.

**Issue: Application doesn’t start**  
- Ensure you extracted the entire folder, not just the .exe.  
- Check that your antivirus isn’t quarantining the file. Add an exception if needed.  
- Run the .exe as Administrator (right-click → **"Run as administrator"**).

**Issue: Script errors or crashes**  
- Update to the latest version by re-downloading the zip from the link above.  
- Disable any third-party Roblox injectors that may conflict.  
- Restart the app and try a simpler script to isolate the problem.

**Issue: No internet access from scripts**  
- By default, network is blocked. Enable it in **Settings** → **Permissions** → **Allow Network** if you trust the script.
